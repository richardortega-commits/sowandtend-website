# Sow & Tend website

## Working files
- `index.html`: current homepage, new logo, browser icon, and page scrolling fix.
- `assets/sow-and-tend-logo.png`: horizontal website logo.
- `assets/sow-and-tend-app-icon.png`: browser tab and Apple touch icon.

- Other assets are retained for future website work.

## Publish
Open this folder in GitHub Desktop. Review changes, commit to main, and push origin. Vercel uses the existing GitHub connection to publish.

The existing Git history and local Vercel connection are preserved. Older pages, design source files, duplicates, and unrelated Sales Thru Service artwork are in the separate archive ZIP. Do not copy the archive into this website folder.
